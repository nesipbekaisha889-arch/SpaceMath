# SpaceMath
Ғарыш сыры (SpaceMath) — математика мен ғарышты біріктіретін интерактивті білім беру жобасы. Ойыншылар 8-сынып математикасының тақырыптары бойынша есептер шешіп, ғарыштық миссияларды орындайды, планеталарды зерттейді және ғарыш кемесімен жаңа әлемдерге саяхат жасайды. Жобаның мақсаты — математикалық білімді қызықты әрі ойын арқылы меңгерту.
